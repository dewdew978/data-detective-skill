# Contributing

Thanks for helping improve Data Detective.

1. Open an issue describing the problem or proposed feature.
2. Keep CSV parsing and validation offline and read-only.
3. Add regression tests for bug fixes and metric changes.
4. Run `python -m unittest discover -s tests -v`.
5. Send a pull request describing behavior, tests, and any privacy implications.

Please use synthetic, non-sensitive CSV files in tests and bug reports. Never commit real customer datasets.
